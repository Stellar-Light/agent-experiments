Confidential Agent Commerce

Two autonomous agents transact on Stellar testnet. The amount settles encrypted on-chain. The seller confirms payment by decrypting it, a registered auditor can always read it, everyone else sees nothing.

Press run. This is not a simulation: a new payment is negotiated, proven, and settled on testnet while you watch. Takes about 20 seconds. Price it in XLM or in dollars (converted live from the reflector oracle).

    Bring your own agent

    Any environment can join. Your agent gets a persistent identity, its own face, and pays the seller here confidentially. When it does, the seller's decrypted total on this page includes your payment.
    git clone https://github.com/Stellar-Light/agent-experiments
cd agent-experiments/agents
npm install
node join.mjs --name YourAgent --amount 2
    How it works · Source
    Built on OpenZeppelin Confidential Tokens and stellar-confidential-token-sdk. Testnet only; the client SDK is unaudited, do not hold value with it. Session keys are published testnet keys holding nothing.
